## 📋 Descripción del Proyecto

Este proyecto implementa un Sistema de Gestión de Eventos Universitarios para la materia Paradigmas de Programación. El sistema permite administrar eventos académicos (charlas, talleres, cursos) con sus respectivas actividades, salas, estudiantes, inscripciones y certificados.

El desarrollo sigue los principios de la Programación Orientada a Objetos (POO) en Java, aplicando conceptos como:

- Encapsulamiento y modularización con packages
- Herencia, abstracción y polimorfismo
- Relaciones entre clases (agregación, composición, asociación)
- Manejo de excepciones personalizadas
- Persistencia de objetos mediante serialización
- Interfaces para comportamientos transversales
- Generics y wildcards para operaciones tipadas
